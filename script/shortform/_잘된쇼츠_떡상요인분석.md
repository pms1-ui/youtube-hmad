# 헬마드 — 조회수 잘 나온 쇼츠 12개 떡상 요인 분석

분석 대상: `_잘된쇼츠12_대본모음.txt` (실제 조회수 잘 나온 12편)

---

## 1. 주제 성격 (무엇을 다뤘나)

12편을 성격으로 분류하면 뚜렷한 4개 축이 보인다.

| 축 | 편수 | 해당 편 |
|----|:---:|------|
| **A. 즉효성 뷰티/외모 꿀팁** (헬스인데 외모까지) | 3 | 귀고무줄 소안면, 뮤잉 턱선, 파스타(붓기·다이어트) |
| **B. 통념을 깨는 반전 지식** | 3 | 체지방=호흡, 카프킥vs로우킥, 파스타(밀가루인데 건강식) |
| **C. 사람/사례 스토리 (감정 이입)** | 3 | 암투병 턱걸이, 팔13cm 사례, 흑인 운동능력 |
| **D. 강렬한 구경거리/유머** | 3 | 데빌프레스(극한), 헬스장 빌런(유머), 흑인 운동능력(충격) |

**핵심 인사이트:** 순수 "운동 루틴 소개"는 거의 없다. 전부 **운동 + α**(외모/과학반전/사람이야기/충격)로 후크를 건다. 헬스 채널이지만 "헬스 밖의 욕망"(작은 얼굴, 콤플렉스 해소, 신기함, 감동)을 건드린 게 공통점.

## 2. 논리 / 전개 구조 (공통 뼈대)

12편 거의 전부가 아래 4단 구조를 따른다. **초반에 답을 안 준다.**

```
① 후크 (0~3초): 충격 선언 / 반전 예고 / 궁금증. "결과·현상"만 던지고 "이유·방법"은 감춤.
② 긴장 유지 (3~10초): "왜?", "대체 뭐길래?" 되물으며 정보를 조금씩 흘림. 통념을 먼저 세움.
③ 정체 공개 + 원리 (10~40초): 그제서야 정답(운동명/음식명/원리) 공개 + 과학·수치 근거.
④ 실천/마무리 (40~55초): 따라 할 방법 or 여운(스토리형은 감동/응원 유도).
```

**편별 후크 문장 (0~3초) 실제 예:**
- "귀에 고무줄을 걸었을 뿐인데 얼굴에 놀라운 변화가 발생합니다" → 현상만, 원리 감춤
- "대부분의 격투 단체에서 로우킥을 쓰는 선수가 사라졌습니다. 대체 왜?" → 반전 현상 + 질문
- "체지방, 도대체 어디로 배출되는지" → 누구나 안 궁금했던 걸 궁금하게
- "이 마르고 앙상한 남자는 팔 둘레를 무려 13cm 늘리는 데 성공합니다" → 결과 먼저, 방법 감춤
- "아무리 열심히 운동해도 어깨가 안 커지는 건 다 이유가 있습니다" → 손해/원인 예고

**공통 규칙:** 첫 문장에 "정답"이 없다. 첫 문장엔 "놀라운 결과 / 이상한 현상 / 내 손해"만 있고, 정답은 중반 이후로 미룬다. → 시청지속 확보.

## 3. 타입 (형식적 유형)

| 타입 | 설명 | 해당 편 |
|------|------|------|
| **원리설명형** | 현상→원리→방법. 정보 전달이 주. | 귀고무줄, 뮤잉, 체지방, 데드행, YTW, 파스타 |
| **지식반전형** | 통념을 세우고 뒤집기. | 카프킥, 체지방, 파스타 |
| **사례/내러티브형** | 특정 인물의 변화·사연 3인칭 서술. | 암투병 턱걸이, 팔13cm, 흑인 |
| **관찰/유머형** | 3인칭 상황 중계, 웃음. | 헬스장 빌런 |
| **극한소개형** | "가장 힘든/센" 것 소개, 도전 욕구. | 데빌프레스 |

**빈도 높은 승자 타입:** 원리설명형(특히 외모/즉효성) + 지식반전형. 이 둘이 절반 이상.

## 4. 떡상할 수밖에 없었던 이유 (심리 트리거)

1. **"헬스 + 외모" 교집합** — 운동 채널인데 "작은 얼굴, 턱선, 붓기"를 다룬다. 헬스 시청자 + 뷰티 관심층을 동시에 흡수. 도구도 0원(고무줄·혀·맨몸)이라 진입장벽 제로 → 저장·공유·따라하기 유발.
2. **즉시 따라 할 수 있음 (제로 비용)** — 고무줄 2개, 혀 위치, 철봉 매달리기, 운동 전 30번. 장비·헬스장 없이 오늘 당장. "나도 되겠다"는 실행 가능성이 저장을 부른다.
3. **통념 파괴의 쾌감** — "땀으로 빠지는 게 아니라 숨으로", "밀가루인데 다이어트식", "로우킥이 사라진 이유". 알고 있던 상식이 깨지는 순간 끝까지 본다.
4. **결과를 먼저, 방법을 나중에** — 13cm, 56개 논스톱, 성형한 듯한 얼굴. 강렬한 숫자·결과를 앞세워 "어떻게?"를 궁금하게 만든 뒤 방법을 뒤에 배치.
5. **감정 이입 / 논쟁성** — 암투병 스토리(감동·응원 댓글 유도), 흑인 신체 이슈(논쟁·댓글 폭발). 댓글이 많이 달릴 소재 = 알고리즘 가속.
6. **구체적 숫자·권위** — "840g은 이산화탄소로", "GI 40~55 vs 쌀밥 92", "팔 5인치=13cm", "5초 3번→10초 5번". 숫자가 신뢰와 저장 욕구를 만든다.
7. **명확한 원 메시지** — 한 편에 주장 하나. 곁가지 없음. 55초 안에 "이거 하나" 남긴다.

## 5. 말투 / 톤

- **종결어미:** ∼니다 / ∼데요 / ∼죠 / ∼구요 중심. "∼해요/∼하세요" 없음. (헬마드 규칙과 일치)
- **3인칭 관찰 서술이 잦음:** "이 남자는∼", "한 여자가∼", "∼했다고 하죠", "∼하는데요". 스토리·사례·유머형에서 강력.
- **직접 말 걸기:** "∼해보셨을 겁니다", "맞아본 분들은 아시겠지만", "∼하는 건 어떨까요". 공감·참여 유도.
- **적당한 호들갑·과장:** "놀라운 변화", "죽음을 맛볼 수 있습니다", "성형수술 받은 듯", "떡상할 겁니다". 밋밋하지 않게.
- **마무리 CTA:** 스토리형은 "응원 댓글 남겨주세요", 정보형은 "오늘부터 30번씩 해보세요 / 도전해 보시는 건 어떨까요 / 꿀팁 댓글로". 부드러운 참여 유도(구독 강요 아님).

## 6. 분량 / 호흡

- **글자 수:** 자막 기준 약 330~590자 (정리본 기준). 대략 **한 편 300~450자 내외**가 스윗스팟. → 45~60초 분량.
- **문장:** 짧고 끊어치기. 한 문장 = 한 정보. 접속사로 길게 늘이지 않음.
- **정보 밀도:** 55초 안에 후크 1 + 통념/긴장 1~2 + 원리 1~2 + 수치 1~2 + 마무리 1. 군더더기 없음.
- **속도감:** 도입 3초 안에 반드시 후크. 늘어지는 배경 설명 없음.
