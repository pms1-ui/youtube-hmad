────────────────────────────────────────────────────────────
■ Higgsfield 사용 가이드 (모든 클립 공통)
────────────────────────────────────────────────────────────
- 방식: Image-to-Video. 각 장면 이미지를 첫 프레임으로 올리고 아래 "Motion Prompt"를 입력.
- 길이: 클립당 3∼5초 (쇼츠 총 40∼55초 목표). 대사 긴 5·6·11번은 5초, 나머지 3∼4초.
- 화면비: 9:16 세로 유지. Camera Fixed 옵션은 카메라 지시가 "고정"인 장면에만 사용.
- 캐릭터 일관성: 실버 메탈릭 바디빌더 외형·HMAD 캡·재질은 절대 변하지 않게. 얼굴 이목구비 새로 생성 금지(featureless silver face 유지).
- 소품 일관성: 흰색 반투명 셰이커 / 화이트 라벨 통 / 그릴자국 닭가슴살 톤 유지.
- 모션 강도: subtle∼medium. 과한 왜곡·순간이동·소품 개수 변화 금지.
- ★ 꼬리 문구는 아래 12개 Motion Prompt 각각에 이미 직접 포함되어 있음(복붙 후 그대로 사용).
  배경 유지 문구는 그룹별로 다름: 1∼3 Korean gym / 4∼6 Korean home kitchen / 7∼9 Korean hanok / 10∼12 Korean convenience store.
  (기본형: "Metallic silver bodybuilder character stays identical, HMAD cap fixed, props consistent, no morphing, no extra limbs, smooth natural motion, 9:16 vertical, keep the same [배경] background.")
